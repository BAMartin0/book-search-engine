# Book Search Engine

## Description
The Book Search Engine is a web application built with the MERN stack (MongoDB, Express.js, React, Node.js). It enables users to search for books via the Google Books API, view details about selected books, save books to their personal account, and remove saved books as desired. This app includes user authentication to provide personalized experiences, ensuring that saved books are tied to individual accounts.

## Features
Search Books: Look up books using the Google Books API.
User Authentication: Register, log in, and log out securely.
Save Books: Add books to a personal saved list.
Remove Books: Remove books from your saved list.
Responsive Design: Works seamlessly on various devices.

## Technologies
This app is built using the following technologies:

MongoDB: NoSQL database for storing user data and saved books.
Express.js: Backend framework for server-side operations.
React: Frontend library for building the user interface.
Node.js: JavaScript runtime for server-side execution.
GraphQL & Apollo Client: For API interactions and data management.
JWT Authentication: Secure user login system.

## Installation
- On the homepage of the repo click the `GREEN` code button and copy the `SSH`.
- Clone this repo using the `SSH` in the terminal
- Run `NPM install` in the root directory  
- To start run the code run "NPM run build" in the terminal.
- Finally, run "npm run develop"

## Usage
Register an Account:
Navigate to the app and sign up with a new account.

Search for Books:
Use the search bar on the homepage to find books by title, author, or keyword.

Save Books:
Click the "Save" button on a book to add it to your list.

View Saved Books:
Go to the "Saved Books" section to view all books saved to your account.

Remove Books:
Click "Remove" to delete a book from your saved list.

Log Out:
Click "Log Out" to securely end your session.
